# Circuit Network Inspector

Utility mod for Factorio 2.1

Open an entity GUI that has circuit connections. The mod adds a small `ⓘ`
button next to Factorio's additional-entity-info area. Clicking it opens a
circuit-network inspector.

The inspector shows:
* all entities connected to that network
* which signals do these entities read & write?
* you can filter for signals

Understanding those platform-wide circuit networks should be easier now!
